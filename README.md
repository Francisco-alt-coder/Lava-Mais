# Lava Mais

O Lava Mais é uma aplicação web acadêmica para explorar serviços de lavagem de veículos, consultar estabelecimentos, simular um agendamento e acompanhar as etapas do pedido.

O projeto foi desenvolvido na disciplina Programação para Web, do curso de Análise e Desenvolvimento de Sistemas.

## O que você pode fazer

- Explorar os lava-jatos apresentados na aplicação.
- Consultar serviços e detalhes dos estabelecimentos.
- Escolher o tipo de veículo, serviço, data e horário.
- Simular o agendamento e acompanhar as etapas do pedido.
- Consultar a tela de entrega do veículo.
- Usar a interface em computador ou celular.

## Como executar

Você precisa ter o **Node.js 20 ou superior** instalado. A instalação do Node.js também disponibiliza o npm.

Confira se estão instalados abrindo o terminal e digitando:

```bash
node --version
npm --version
```

### Opção mais fácil no Windows

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Dê dois cliques no arquivo **iniciar.bat**.
4. Aguarde a preparação e a abertura do navegador.
5. Se o navegador não abrir automaticamente, acesse [http://localhost:3000](http://localhost:3000).

Na primeira execução, é necessário estar conectado à internet para instalar as dependências. Mantenha a janela aberta enquanto estiver usando a aplicação. Para encerrá-la, pressione **Ctrl + C** nessa janela.

### Executar pelo terminal

Na pasta do projeto, rode:

```bash
npm ci
npm start
```

Depois, abra [http://localhost:3000](http://localhost:3000) no navegador. Para parar o servidor, volte ao terminal e pressione **Ctrl + C**.
